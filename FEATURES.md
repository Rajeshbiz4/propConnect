# Feature Coverage

## Included in this code
- Agent registration/login/logout
- Password reset development flow
- Dashboard counters
- Property CRUD-style management (archive instead of hard delete)
- Property duplication
- Rent/sale and flat/plot/business property fields
- Images, cover image and removal
- Amenities, location and Google Maps link
- Unique public URL for every agent
- Public property catalogue
- Public filters
- Public property details
- Call/WhatsApp contact
- Enquiry capture and enquiry status management
- Agent profile/public URL settings
- Admin dashboard, agent status and global property review
- Responsive desktop/mobile UI

## Deliberately left as integration extensions
The earlier specification also contained future-phase features such as online payments, subscription billing, AI recommendations, AI image enhancement, rent collection, agreement e-signing, owner accounting, and native mobile apps. Those depend on third-party provider choices and business rules, so they are not stubbed with fake implementations in this ZIP.
